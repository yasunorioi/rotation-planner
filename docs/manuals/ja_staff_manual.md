## 1. ログインと権限

### ログイン

1. ブラウザで `http://localhost:7863` にアクセス
2. JA職員用アカウントでログイン

### JA職員の権限

| 機能 | 農家 | JA職員 | 管理者 |
|------|:----:|:------:|:------:|
| 自分のデータ管理 | ○ | ○ | ○ |
| 担当農家一覧閲覧 | × | ○ | ○ |
| 農薬発注集計 | × | ○ | ○ |
| 防除マスタ編集 | × | ○ | ○ |
| ユーザー管理 | × | × | ○ |

## 2. JA集計画面

担当する農家全体の農薬発注状況を一覧・集計します。

### アクセス方法

1. 「📊 JA集計」タブをクリック

### 画面構成

#### 組織統計

ダッシュボード上部に表示:
- **担当農家数**: 管轄する農家の総数
- **総ほ場数**: 登録されているほ場の総数
- **総面積**: 管轄農家の総耕作面積（ha）

#### 担当農家一覧

| 項目 | 説明 |
|------|------|
| ID | 農家のユーザーID |
| 農家名 | 表示名またはユーザー名 |
| ほ場数 | 登録されているほ場数 |
| 総面積(ha) | 農家ごとの総面積 |

「🔄 農家一覧を更新」ボタンで最新データを取得。

#### 農家別発注状況

期間を指定して、農家ごとの発注状況を検索できます。

1. **開始日**と**終了日**を入力（YYYY-MM-DD形式）
2. 「🔍 検索」ボタンをクリック

表示項目:
- 農家名
- 発注日
- 農薬名
- 数量
- 単位
- 状態（draft/submitted/confirmed）

#### 組織全体の農薬発注集計

年度を指定して、組織全体の農薬必要量を集計します。

1. **対象年**を選択
2. 「📊 集計」ボタンをクリック

表示項目:
- 農薬名
- 総必要量
- 単位
- 発注農家数

### エクスポート

集計結果をCSVでエクスポート:
1. 集計を実行
2. 「📄 CSV出力」ボタンをクリック
3. ファイルがダウンロードされる

## 3. 防除マスタ管理

農薬と作物の対応関係（防除マスタ）を管理します。

### アクセス方法

1. 「💊 防除マスタ」タブをクリック

### マスタの構成

| 項目 | 説明 |
|------|------|
| 農薬名 | 農薬の名称 |
| 対象作物 | 適用作物 |
| 対象病害虫 | 適用となる病害虫 |
| 使用量 | 10aあたりの使用量 |
| 単位 | L, kg, mL など |
| 希釈倍率 | 希釈して使用する場合 |
| 使用時期 | 月（1-12） |

### マスタの追加

1. フォームに必要事項を入力
2. 「💾 登録」ボタンをクリック

### マスタの編集

1. 一覧から対象行を選択
2. フォームに内容が表示される
3. 編集して「💾 更新」ボタンをクリック

### マスタの削除

1. 一覧から対象行を選択
2. 「🗑️ 削除」ボタンをクリック
3. 確認ダイアログで「OK」

### FAMICデータとの連携

農林水産消費安全技術センター（FAMIC）の農薬登録情報を参照できます。

- **pesticide_registry**: 農薬登録基本情報（約4,000件）
- **pesticide_usage**: 適用情報（約10万件）

> **注意**: FAMICデータは参考情報です。実際の使用にあたっては最新の農薬ラベルを確認してください。

## 4. 農家サポート

担当農家からの問い合わせ対応に使用する情報です。

### よくある問い合わせと対応

#### 「ログインできない」

1. ユーザー名を確認
2. パスワードをリセット（管理者に依頼）

#### 「輪作計画が生成できない」

確認事項:
- ほ場が登録されているか → 「JA集計」でほ場数を確認
- 作物設定が完了しているか
- 制約条件が厳しすぎないか

#### 「農薬発注の計算結果がおかしい」

確認事項:
- 防除マスタに対象作物が登録されているか
- 使用量・希釈倍率が正しいか
- 面積の単位（ha/a）が合っているか

#### 「防除記録を入力したい」

操作案内:
1. 「🧪 防除記録」タブ
2. 写真アップロードまたは手動入力
3. 「💾 登録」

## 5. データエクスポート

### JA提出用データ

|--------|------|----------|
| ほ場一覧 | CSV | データ管理 → エクスポート |
| 輪作計画 | CSV | データ管理 → エクスポート |

## 6. トラブルシューティング

### システムエラー

| エラー | 原因 | 対処 |
|--------|------|------|
| 「DB機能が利用できません」 | データベース接続エラー | 管理者に連絡 |
| 「防除マスタが見つかりません」 | マスタ未登録 | 防除マスタを登録 |
| 「ログインが必要です」 | セッション切れ | 再ログイン |

### データ不整合

| 症状 | 確認事項 |
|------|----------|
| 農家数が合わない | org_id（組織ID）の設定を確認 |
| 集計値がおかしい | 発注データのstatusを確認 |
| ほ場が表示されない | 農家のuser_idを確認 |

### パフォーマンス

| 症状 | 対処 |
|------|------|
| 画面が重い | 期間を絞って検索 |
| 集計に時間がかかる | 年度を指定して絞り込み |

## 管理者向け情報

### ユーザー追加

1. 「⚙️ 管理」タブ
2. 「ユーザー管理」セクション
3. 新規ユーザー情報を入力
4. ロールで「ja_staff」を選択
5. 「追加」

### org_id（組織ID）について

JA職員は `org_id` に基づいて担当農家を参照します。

- 同じ `org_id` を持つ農家のみ閲覧可能
- 異なる `org_id` のデータは見えない
