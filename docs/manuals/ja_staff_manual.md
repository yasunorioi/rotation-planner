## 2. JA集計画面

担当する農家全体の農薬発注状況を一覧・集計します。

### アクセス方法

1. 「📊 JA集計」タブをクリック

### 画面構成

#### 組織統計

ダッシュボード上部に表示:
- **担当農家数**: 管轄する農家の総数
- **総ほ場数**: 登録されているほ場の総数
- **総面積**: 管轄農家の総耕作面積（ha）

#### 担当農家一覧

| 項目 | 説明 |
|------|------|
| ID | 農家のユーザーID |
| 農家名 | 表示名またはユーザー名 |
| ほ場数 | 登録されているほ場数 |
| 総面積(ha) | 農家ごとの総面積 |

「🔄 農家一覧を更新」ボタンで最新データを取得。

#### 農家別発注状況

期間を指定して、農家ごとの発注状況を検索できます。

1. **開始日**と**終了日**を入力（YYYY-MM-DD形式）
2. 「🔍 検索」ボタンをクリック

表示項目:
- 農家名
- 発注日
- 農薬名
- 数量
- 単位
- 状態（draft/submitted/confirmed）

#### 組織全体の農薬発注集計

年度を指定して、組織全体の農薬必要量を集計します。

1. **対象年**を選択
2. 「📊 集計」ボタンをクリック

表示項目:
- 農薬名
- 総必要量
- 単位
- 発注農家数

### エクスポート

集計結果をCSVでエクスポート:
1. 集計を実行
2. 「📄 CSV出力」ボタンをクリック
3. ファイルがダウンロードされる

### 地目別面積集計

担当する農家の作付け面積を地目別に集計します。水田・畑・畑地化済みの区分で集計でき、畑地化補助金の管理にも活用できます。

#### アクセス方法

1. 「📊 面積集計」タブをクリック

#### 集計表の構成

クロス集計表の形式で表示されます：

| 列 | 説明 |
|------|------|
| 作物 | 作付けされている作物名 |
| 畑 | 普通畑の面積（ha） |
| 畑地化(YYYY) | 畑地化開始年度別の面積（ha） |
| 畑地化(不明) | 開始年度が記録されていない畑地化済み面積（ha） |
| 水田 | 水田の面積（ha） |
| 合計 | 作物ごとの総面積（ha） |

表の最終行に全作物の合計が表示されます。

#### 操作手順

1. **年度**欄に集計対象年度を入力（例: 2025）
2. 「📊 集計」ボタンをクリック
3. クロス集計表が表示される

表示例:
```
作物名    畑    畑地化(2020)  畑地化(不明)  水田   合計
大豆     5.23    10.50         2.30       0.00  18.03
てんさい 12.00    0.00          0.00       0.00  12.00
合計    17.23    10.50         2.30       0.00  30.03
```

- 面積は小数点以下2桁で表示
- 0.00の場合は「-」（ダッシュ）で表示

#### 畑地化開始年度別の見方

**畑地化済みの区分:**
- **畑地化(2020)**, **畑地化(2021)** 等: 各年度に畑地化を開始したほ場の面積
- **畑地化(不明)**: 畑地化済みだが開始年度が記録されていないほ場の面積

**畑地化補助金について:**
- 畑地化済みのほ場は国の補助金の対象（5年間）
- 開始年度ごとに面積を集計することで、補助金申請の根拠資料となる
- 開始年度が不明な場合は別枠で表示される

#### 補助金サマリ

集計表の下部に「🏦 畑地化補助金サマリ」が表示されます。

| 項目 | 説明 |
|------|------|
| ほ場ID | 対象ほ場の識別番号 |
| 面積(ha) | ほ場の面積 |
| 畑地化開始年 | 畑地化を開始した年度 |
| 残り年数 | 補助金受給残り年数（5年間から経過年数を引いた値） |

**残り年数の計算:**
- 補助金は畑地化開始から5年間
- 残り年数 = 5 - (現在年度 - 開始年度)
- 例: 2020年開始、現在2025年 → 残り年数 = 5 - (2025 - 2020) = 0年（受給期間終了）

#### CSV出力

集計結果をCSVファイルでダウンロードできます。

1. 集計を実行（「📊 集計」ボタン）
2. 「📥 CSV出力」ボタンをクリック
3. `cross_tabulation_YYYY.csv` ファイルがダウンロードされる

**CSV形式:**
- UTF-8（BOM付き）でExcel対応
- ヘッダー行: 作物, 畑, 畑地化(YYYY), ..., 畑地化(不明), 水田, 合計
- データ行: 各作物の面積
- 最終行: 合計

**活用例:**
- JA提出用の集計資料
- 補助金申請の添付資料
- 年度間比較（複数年度のCSVを並べて分析）

## 3. 防除マスタ管理

農薬と作物の対応関係（防除マスタ）を管理します。

### アクセス方法

1. 「💊 防除マスタ」タブをクリック

### マスタの構成

| 項目 | 説明 |
|------|------|
| 農薬名 | 農薬の名称 |
| 対象作物 | 適用作物 |
| 対象病害虫 | 適用となる病害虫 |
| 使用量 | 10aあたりの使用量 |
| 単位 | L, kg, mL など |
| 希釈倍率 | 希釈して使用する場合 |
| 使用時期 | 月（1-12） |

### マスタの追加

1. フォームに必要事項を入力
2. 「💾 登録」ボタンをクリック

### マスタの編集

1. 一覧から対象行を選択
2. フォームに内容が表示される
3. 編集して「💾 更新」ボタンをクリック

### マスタの削除

1. 一覧から対象行を選択
2. 「🗑️ 削除」ボタンをクリック
3. 確認ダイアログで「OK」

### FAMICデータとの連携

農林水産消費安全技術センター（FAMIC）の農薬登録情報を参照できます。

- **pesticide_registry**: 農薬登録基本情報（約4,000件）
- **pesticide_usage**: 適用情報（約10万件）

> **注意**: FAMICデータは参考情報です。実際の使用にあたっては最新の農薬ラベルを確認してください。

## 4. 農家サポート

担当農家からの問い合わせ対応に使用する情報です。

### よくある問い合わせと対応

#### 「ログインできない」

1. ユーザー名を確認
2. パスワードをリセット（管理者に依頼）

#### 「輪作計画が生成できない」

確認事項:
- ほ場が登録されているか → 「JA集計」でほ場数を確認
- 作物設定が完了しているか
- 制約条件が厳しすぎないか

#### 「農薬発注の計算結果がおかしい」

確認事項:
- 防除マスタに対象作物が登録されているか
- 使用量・希釈倍率が正しいか
- 面積の単位（ha/a）が合っているか

#### 「防除記録を入力したい」

操作案内:
1. 「🧪 防除記録」タブ
2. 写真アップロードまたは手動入力
3. 「💾 登録」

## 6. トラブルシューティング

### システムエラー

| エラー | 原因 | 対処 |
|--------|------|------|
| 「DB機能が利用できません」 | データベース接続エラー | 管理者に連絡 |
| 「防除マスタが見つかりません」 | マスタ未登録 | 防除マスタを登録 |
| 「ログインが必要です」 | セッション切れ | 再ログイン |

### データ不整合

| 症状 | 確認事項 |
|------|----------|
| 農家数が合わない | org_id（組織ID）の設定を確認 |
| 集計値がおかしい | 発注データのstatusを確認 |
| ほ場が表示されない | 農家のuser_idを確認 |

### パフォーマンス

| 症状 | 対処 |
|------|------|
| 画面が重い | 期間を絞って検索 |
| 集計に時間がかかる | 年度を指定して絞り込み |

## 管理者向け情報

### ユーザー追加

1. 「⚙️ 管理」タブ
2. 「ユーザー管理」セクション
3. 新規ユーザー情報を入力
4. ロールで「ja_staff」を選択
5. 「追加」

### org_id（組織ID）について

JA職員は `org_id` に基づいて担当農家を参照します。

- 同じ `org_id` を持つ農家のみ閲覧可能
- 異なる `org_id` のデータは見えない
