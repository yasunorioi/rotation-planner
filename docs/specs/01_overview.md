## 1. システム概要

### 1.1 目的

rotation_planner_ui は、北海道畑作農家向けの統合農業管理アプリケーションである。
以下の業務を一元的にサポートする:

- ほ場（農地）の登録・管理
- 輪作計画の自動生成と管理
- 農薬発注量の算出
- 作付履歴の管理

### 1.2 対象ユーザー

| ユーザー種別 | 説明 |
|-------------|------|
| 農家 (farmer) | 自身のほ場データを管理し、輪作計画を作成する |
| JA職員 (ja_staff) | 組織内の全農家データを参照・管理する |
| 管理者 (admin) | システム全体の設定・ユーザー管理を行う |

### 1.3 動作環境

| 項目 | 要件 |
|------|------|
| サーバーサイド | Python 3.11以上 |
| フレームワーク | Gradio 4.0以上 |
| データベース | SQLite |
| 推奨メモリ | 512MB以上 |
| 動作確認済みOS | Debian 12 / Ubuntu 22.04 |

#### 主要依存ライブラリ

```

ortools          # 最適化ソルバー（輪作計画生成）

```

## 2. ユーザーロールと権限

### 2.1 ロール定義

| ロール | 定数名 | 説明 |
|--------|--------|------|
| 管理者 | `ROLE_ADMIN` | システム全機能へのアクセス権 |
| JA職員 | `ROLE_JA_STAFF` | 組織内全農家データへのアクセス権 |
| 農家 | `ROLE_FARMER` | 自身のデータのみアクセス可能 |

### 2.2 権限マトリクス

| 機能 | admin | ja_staff | farmer |
|------|:-----:|:--------:|:------:|
| **ホームタブ** | O | O | O |
| **作物設定タブ** | O | O | O |
| **ほ場登録タブ** | O | O | O |
| **作付履歴タブ** | O | O | O |
| **輪作計画タブ** | O | O | O |
| **農薬発注タブ** | O | O | O |
| **データ管理タブ** | O | O | O |
| **農家一覧タブ** | O | O | - |
| **防除マスタタブ** | O | O | - |
| **管理タブ** | O | - | - |

- `O`: アクセス可能
- `-`: アクセス不可

### 2.3 データアクセス制御

```python
# 管理者・JA職員は全農家データにアクセス可能
ADMIN_ROLES = {ROLE_ADMIN, ROLE_JA_STAFF}

def can_access_farmer(username, farmer_id):
    """特定農家データへのアクセス権限チェック"""
    if user.role in ADMIN_ROLES:
        return True  # 全農家にアクセス可能
    return user.farmer_id == farmer_id  # 自分のデータのみ
```

## 3. 機能一覧

### 3.1 タブ構成と機能概要

| タブ名 | 機能概要 | 主要コンポーネント |
|--------|----------|-------------------|
| ホーム | ワークフロー案内、機能一覧表示 | - |
| 作物設定 | 作付する作物の選択・カスタム作物追加 | `crop_settings.py` |
| ほ場登録 | 地図上でのほ場登録、面積計算 | `field/ui.py`, `field/map.py` |
| 作付履歴 | 過去の作付履歴の管理・連作警告 | `crop_history/ui.py` |
| 輪作計画 | 最適化エンジンによる輪作計画生成 | `app/optimizer.py`, `app/ui.py` |
| 農薬発注 | 輪作計画からの農薬必要量算出 | `pesticide/ui.py` |
| データ管理 | CSV一括インポート/エクスポート | `data_management/ui.py` |
| 農家一覧 | 組織内農家の統計表示 | portal.py 内 |
| 防除マスタ | 農薬・防除情報の管理 | `pesticide_master_ui.py` |
| 管理 | ユーザー管理、システム設定 | `admin_ui.py` |

### 3.2 各機能の詳細

#### 3.2.1 作物設定

- 作物マスタからの作物選択（チェックボックス）
- カスタム作物の追加（例: 「ブロッコリー（2作目）」）
- 親作物との紐付け（防除マスタ連携用）
- 自動保存機能

#### 3.2.2 ほ場登録

- Leaflet.js による地図表示
- ポリゴン描画によるほ場境界登録
- WGS84楕円体による正確な面積計算（pyproj使用）
- 筆ポリゴン（農水省公開データ）からの自動取り込み
- 住所検索機能（Nominatim API）
- KML/KMZインポート・エクスポート

#### 3.2.3 作付履歴

- ほ場 x 年度のマトリックス形式表示
- 直接編集可能なテーブル
- 連作障害の自動警告（てんさい4年、馬鈴薯4年など）
- 推論補完データの*マーク表示
- CSVエクスポート機能

#### 3.2.4 輪作計画

- OR-Tools CP-SATソルバーによる最適化
- ヒューリスティック最適化（フォールバック）
- 制約設定:
  - 面積上限/下限
  - 作付間隔（連作障害対策）
  - ほ場数制限（最小/最大）
  - 禁止遷移（てんさい→秋小麦 等）
  - 優先遷移
  - 地区まとめ優先
- 固定の禁止遷移:
  - てんさい→秋小麦（作期重複）
  - 春小麦→秋小麦（病害対策）
  - 同一作物の連作禁止
- 感度分析（ボトルネック制約の特定）
- 計画のDB保存・読み込み

#### 3.2.5 農薬発注

- 輪作計画からの農薬必要量自動計算
- 防除マスタ連携
- 月別詳細スケジュール表示
- DB保存機能
- PDF出力機能（reportlab使用）
- 保存済み発注リストの管理

#### 3.2.6 データ管理

- ほ場データのCSVインポート/エクスポート
- 輪作計画のCSVインポート/エクスポート
- バリデーション機能:
  - 必須項目チェック
  - 作物設定との整合性チェック
  - 連作障害の警告

#### 3.2.7 管理機能（admin専用）

- ユーザー管理（追加/削除/パスワードリセット/ロール変更）
- システム情報表示
- データバックアップ
- 筆ポリゴンアップロード
- デバッグモード切り替え

### 4.3 初期設定フロー（新規ユーザー向け）

1. **ログイン** - 管理者が発行したアカウントでログイン

3. **ほ場登録** - 地図上で自身のほ場を登録

5. **輪作計画生成** - 「登録済みほ場を読み込む」→「計画を生成」

## 6. データモデル

### 6.1 主要テーブル

| テーブル名 | 説明 |
|------------|------|
| users | ユーザー情報 |
| organizations | 組織（JA等） |
| fields | ほ場情報 |
| crop_history | 作付履歴 |
| rotation_plans | 輪作計画 |
| plan_details | 輪作計画詳細 |
| pesticide_orders | 農薬発注リスト |
| pesticide_masters | 防除マスタ |
| crop_master | 作物マスタ |
| user_crops | ユーザー作物設定 |

### 6.2 主要エンティティ

```python
@dataclass
class Field:
    """ほ場情報"""
    id: int
    user_id: int
    field_code: str      # ほ場コード（例: F001）
    name: str            # ほ場名
    district: str        # 地区
    area_ha: float       # 面積（ha）
    beet_forbidden: bool # てんさい禁止フラグ
    coordinates_json: str # 座標データ（GeoJSON）

@dataclass
class RotationPlan:
    """輪作計画"""
    id: int
    user_id: int
    name: str
    start_year: int
    end_year: int
    constraints_json: str  # 制約設定
    details: List[PlanDetail]  # ほ場×年の作付
```
