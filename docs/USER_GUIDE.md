# 農業管理アプリ ユーザーガイド

## はじめに

### このガイドについて

本書は「農業管理アプリ（rotation-planner）」の操作マニュアルです。北海道畑作農家向けの統合農業管理アプリとして、ほ場管理から輪作計画、農薬発注までを一元管理できます。

### 対象ユーザー

| ロール | できること |
|--------|-----------|
| **農家（farmer）** | 作物設定、ほ場登録、輪作計画、農薬発注、防除記録、データ管理 |
| **JA職員（ja_staff）** | 農家の全機能 + JA集計 + 防除マスタ管理 |
| **管理者（admin）** | 全機能 + ユーザー管理 + システム設定 + バックアップ |

### 動作環境

- **ブラウザ**: Google Chrome、Firefox、Safari、Edge（最新版推奨）
- **画面サイズ**: PC推奨（タブレットでも操作可能）
- **インターネット**: 地図表示に必要（OpenStreetMap使用）

## ログインと初期設定

### ログイン手順

1. ブラウザでアプリのURLにアクセスする
2. ユーザー名とパスワードを入力する
3. 「ログイン」ボタンをクリックする
4. ホーム画面が表示される

### 初期ユーザー

| ユーザー名 | パスワード | ロール |
|-----------|-----------|--------|
| admin | admin123 | 管理者 |
| ja_staff | ja123 | JA職員 |
| farmer_demo | demo123 | 農家（デモ用） |

> **重要**: 初回ログイン後、必ずパスワードを変更してください。変更方法は「管理者向け機能」の「パスワードリセット」を参照してください。

### ホーム画面の見方

ログイン後、画面上部にユーザー情報が表示されます。

- **ユーザー名**: 現在ログイン中のユーザー
- **ロール**: 農家 / JA職員 / 管理者
- **統計カード**: 登録ほ場数や作付履歴などの概要

画面上部のタブで各機能に切り替えます。

## 🌱 作物設定

輪作計画やほ場登録で使用する作物を選択・管理します。

### マスタ作物の選択

1. 「🌱 作物設定」タブをクリックする
2. 作物一覧のチェックボックスが表示される
3. 作付けする作物にチェックを入れる
4. チェックの変更は**自動保存**される（保存ボタン不要）

> チェックを入れた作物が、ほ場登録や輪作計画の作物選択肢に反映されます。

### カスタム作物の追加

同一作物を複数区分で管理したい場合（例: ブロッコリーの2作目）に使います。

1. 「カスタム作物追加」セクションを開く
2. 「親作物」ドロップダウンからベースとなる作物を選ぶ
3. 「カスタム名」に名前を入力する（例: `ブロッコリー（2作目）`）
4. 「追加」ボタンをクリックする

### カスタム作物の削除

1. 「登録済みカスタム作物」テーブルで対象を確認する
2. 「削除」ボタンをクリックする

## 🗺️ ほ場登録

地図上でほ場の境界を描画し、登録します。

### 地図でほ場を登録する

1. 「🗺️ ほ場登録」タブをクリックする
2. 地図が表示される。自分の農場付近に移動する
   - **住所検索**: 住所欄に住所を入力し「検索」をクリックすると、地図がその場所に移動する
3. 地図左側の描画ツール（多角形アイコン）をクリックする
4. ほ場の境界をクリックしてポリゴンを描く。最後に始点をクリックして閉じる
5. 座標データが自動で入力される
6. 以下の項目を入力する：
   - **ほ場ID**: ほ場の識別番号（例: F001）
   - **地区**: 地区名（例: 北地区）
   - **ほ場名**: ほ場の名前（例: 北圃場）
   - **作付年度**: 現在の作付年度
   - **作物**: 今年の作物（作物設定で選んだものから選択）
   - **馬鈴薯禁止 / てんさい禁止**: 該当する場合チェック
7. 「登録」ボタンをクリックする

### KML/KMZファイルからインポートする

Google Earthなどで作成したKML/KMZファイルから一括登録できます。

1. 「KML/KMZインポート」セクションを開く
2. KMLまたはKMZファイルをアップロードする
3. プレビューテーブルが表示される
4. 必要に応じて各ほ場の作物やてんさい禁止フラグを編集する
   - 「全体に適用」機能で、全ほ場に同じ作物やフラグを一括設定可能
5. 「一括登録」ボタンをクリックする

### ほ場をエクスポートする

1. 「エクスポート」セクションで形式（KML / KMZ）を選ぶ
2. 「ダウンロード」ボタンをクリックする
3. ファイルが保存される

### 登録済みほ場の確認

画面下部の一覧テーブルに、登録済みほ場が表示されます（ほ場ID、名前、地区、面積）。

### ほ場の削除

1. 「ほ場削除」セクションを開く
2. 削除するほ場IDを入力する
3. 「削除」ボタンをクリックする

## 🗺️ ほ場一覧・編集

登録済みほ場を年度別に一覧表示し、作物割当や情報を編集します。

### ほ場一覧の表示

1. 「🗺️ ほ場一覧」タブをクリックする
2. 「開始年度」と「終了年度」を令和形式で選ぶ（例: R5〜R9）
3. マトリックス形式の表が表示される（行: ほ場、列: 年度ごとの作物）

### ほ場情報の編集

1. テーブルの行をクリックしてほ場を選択する
2. 編集フォームが表示される：
   - ほ場ID、ほ場名、地区、面積(ha)、てんさい禁止フラグ
3. 内容を変更する
4. 「保存」ボタンをクリックする

### 年度別の作物を変更する

1. ほ場を選択した状態で「年度別作物編集」セクションを使う
2. 対象年度をドロップダウンから選ぶ
3. 作物をドロップダウンから選ぶ
4. 「保存」ボタンをクリックする

> 輪作計画の微調整にも使えます。

## 🏞️ 水田ポリゴン管理

水田の境界をポリゴンとして登録し、畑地化フラグを管理します。

### 水田ポリゴンの登録

1. 「🏞️ 水田ポリゴン」タブをクリックする
2. 「ほ場」ドロップダウンから対象ほ場を選ぶ
3. 「新規登録」セクションで以下を入力する：
   - **GeoJSON**: 水田の境界座標（地図ツールまたはKMLから取得）
   - **畑地化済**: 畑地化している場合チェック
   - **畑地化開始年度**: 畑地化を始めた年度（例: 2022）
   - **ソース**: manual（手動）/ kml / maff（農水省データ）
   - **メモ**: 備考
4. 「登録」ボタンをクリックする

### KMLからインポートする

1. 「KMLインポート」セクションを開く
2. 作物名を選択する
3. KML/KMZファイルをアップロードする
4. インポートを実行する

### 畑地化フラグについて

- **畑地化済 = ON**: その水田は畑地化されたことを意味する
- **畑地化開始年度**: 補助金の残り年数を計算するために使用（5年間）
- 開始年度が不明な場合は空欄でも登録可能（集計で「不明」として扱われる）

## 🌾 作付けポリゴン管理

ほ場ごと・年度ごとの作付けポリゴンを管理します。

### 作付けポリゴンの表示

1. 「🌾 作付けポリゴン」タブをクリックする
2. 「ほ場」ドロップダウンでほ場を選ぶ
3. 「年度」を入力する
4. 「表示」ボタンをクリックする
5. そのほ場・年度の作付けポリゴン一覧が表示される

### 新規登録

1. 「新規登録」セクションを開く
2. 作物名をドロップダウンから選ぶ（手入力も可）
3. GeoJSON形式で座標を入力する
4. メモ（任意）を入力する
5. 「登録」ボタンをクリックする

### KMLからインポートする

1. 「KMLインポート」セクションを開く
2. 作物名を選択する
3. KML/KMZファイルをアップロードする

### 前年コピー

毎年の作付けが似ている場合、前年のポリゴンをコピーできます。

1. 「前年コピー」ボタンをクリックする
2. 前年（年度 - 1）のポリゴンがコピーされる

## 📊 地目別集計

作物と地目（畑/畑地化済/水田）のクロス集計表を表示します。

### 集計の実行

1. 「📊 面積集計」タブをクリックする
2. 対象年度（西暦）を入力する
3. 「集計」ボタンをクリックする
4. 2つのテーブルが表示される：
   - **クロス集計表**: 作物（行）× 地目（列）の面積
   - **補助金サマリ**: 畑地化開始年度別の面積と残り年数

### クロス集計表の見方

| 作物 | 畑 | 畑地化済 | 水田 | 合計 |
|------|-----|---------|------|------|
| 小麦 | 5.0 | 3.0 | 2.0 | 10.0 |
| だいず | 3.0 | 2.0 | 0.0 | 5.0 |
| ... | ... | ... | ... | ... |

- **畑**: 水田ポリゴンに重ならない部分
- **畑地化済**: 畑地化フラグONの水田ポリゴンと重なる部分
- **水田**: 畑地化フラグOFFの水田ポリゴンと重なる部分

### CSVダウンロード

1. 「CSV出力」ボタンをクリックする
2. クロス集計表がCSVファイルとしてダウンロードされる

## 🌾 輪作計画

OR-Toolsによる最適な輪作計画を自動生成します。

### 制約の設定

1. 「🌾 輪作計画」タブをクリックする
2. 各作物について以下の制約を設定する：
   - **面積上限/下限**: 作付面積の最大・最小値
   - **作付間隔**: 同一ほ場に連作するまでの最短年数
   - **ほ場数制限**: 作付けするほ場の最大数
3. **禁止遷移**: ある作物の次年に植えられない作物の組み合わせ
   - 固定ルール: てんさい→秋小麦（作期重複）、春小麦→秋小麦（病害対策）、同一作物の連作禁止
4. **優先遷移**: 推奨される作物の順番

### 計画の生成

1. 制約を設定後、「最適化実行」ボタンをクリックする
2. ほ場と作付履歴が自動で読み込まれる
3. 計算が完了すると、年度×ほ場の計画表が表示される

### 計画の保存と出力

- **作付履歴に保存**: 「保存」ボタンで計画を作付履歴に直接反映
- **PDF出力**: 「PDF出力」ボタンで印刷用PDFをダウンロード
- **CSV出力**: 「CSV出力」ボタンでCSVファイルをダウンロード

> 生成した計画を微調整したい場合は、「🗺️ ほ場一覧」タブで年度別の作物を個別に変更できます。

## 💊 農薬発注

輪作計画に基づいて年間の農薬必要量を算出します。

### 発注リストの作成

1. 「💊 農薬発注」タブをクリックする
2. 「輪作計画」ドロップダウンから保存済みの計画を選ぶ
3. 「対象年」ドロップダウンから年度を選ぶ（令和形式で表示）
4. 「面積単位」で ha または a を選ぶ
5. 「発注リスト作成」ボタンをクリックする
6. 2つのテーブルが表示される：
   - **農薬別サマリ**: 農薬名、必要量、単位、対象作物、対象病害虫
   - **月別詳細**: 月ごとの散布スケジュール

### 出力と保存

- **CSV出力**: 「CSV出力」ボタンでサマリをCSVダウンロード
- **PDF出力**: 「PDF出力」ボタンで印刷用PDFをダウンロード
- **DBに保存**: 名前を入力して「保存」ボタンで保存

### 保存済み発注リストの管理

1. 「保存済み一覧」セクションを開く
2. 過去の発注リストが一覧表示される
3. 「読み込み」で過去のリストを再表示
4. 「削除」で不要なリストを削除

## 🧪 防除記録

農薬の散布記録を管理します。

### 記録の登録

1. 「🧪 防除記録」タブをクリックする
2. 「📷 記録登録」タブが表示される
3. （任意）写真をアップロードすると、農薬名や散布日時が自動認識される
4. 以下の情報を入力する：
   - **散布日**: YYYY-MM-DD形式
   - **農薬名**: 使用した農薬名
   - **ほ場**: ドロップダウンから選択
   - **希釈倍率**: ドロップダウンから選択（手入力も可）
   - **散布量**: 数値を入力
   - **単位**: L / mL / kg / g から選択
   - **備考**: 任意
5. 「登録」ボタンをクリックする

### 履歴の閲覧

1. 「📋 履歴一覧」タブに切り替える
2. フィルタ条件を設定する（任意）：
   - ほ場、開始日、終了日
3. 「更新」ボタンをクリックする
4. 散布記録が一覧表示される

### 記録の編集・削除

1. 「📋 履歴一覧」タブで対象の記録を確認する
2. 「✏️ 編集」セクションを開く
3. テーブルから対象行を選択し、編集フォームに読み込む
4. 内容を修正して「更新」ボタンをクリックする
5. 削除する場合は「削除」ボタンをクリックする

## 📥 データ管理

CSVファイルによるデータのインポート・エクスポートを行います。

### データのエクスポート（出力）

1. 「📥 データ管理」タブをクリックする
2. 「📤 エクスポート」セクションが表示される
3. 「ほ場一覧CSVエクスポート」ボタンをクリックする
4. CSVファイルがダウンロードされる

### ほ場データのインポート（入力）

1. 「📥 インポート」セクションを開く
2. 「🗺️ ほ場インポート」タブを選ぶ
3. （初回の場合）「サンプルCSV」や「テンプレート」をダウンロードして形式を確認する
4. CSVファイルを準備する
5. ファイルをアップロードする
6. 「インポート実行」ボタンをクリックする
7. 結果とログが表示される

### 輪作計画のインポート

1. 「🌾 輪作計画インポート」タブを選ぶ
2. 「テンプレート」をダウンロードして形式を確認する
3. 計画名を入力する
4. CSVファイルをアップロードする
5. 「インポート実行」ボタンをクリックする

> インポート時にはバリデーション（空欄チェック、未登録作物チェック）が自動で行われます。エラーがある場合は詳細ログに表示されます。

1. 「⚙️ 管理」タブをクリックする
2. 「👥 ユーザー管理」タブを開く
3. 登録済みユーザーの一覧が表示される

#### 新規ユーザーの追加

1. 「➕ 新規ユーザー追加」セクションを開く
2. 以下を入力する：
   - ユーザー名
   - パスワード
   - ロール（admin / ja_staff / farmer）
   - 表示名
3. 「追加」ボタンをクリックする

#### パスワードリセット

1. ユーザー一覧で対象ユーザーの行番号を確認する
2. 「🔧 ユーザー操作」セクションを開く
3. 行番号を入力する
4. 新しいパスワードを入力する
5. 「リセット」ボタンをクリックする

1. 行番号を入力する
2. 新しいロールをドロップダウンから選ぶ

1. 「🗺️ 筆ポリゴン」タブを開く

3. 「アップロード」ボタンをクリックする

- **デバッグモード**: ON/OFFを切り替えられる（開発用。本番ではOFFにする）

## よくある質問（FAQ）

### Q. 作物設定でチェックを入れたのに、ほ場登録の作物選択に出てこない

**A.** 作物設定タブでチェックを入れた後、ほ場登録タブに切り替えると選択肢が自動更新されます。反映されない場合はページを再読み込みしてください。

### Q. KMLファイルのインポートで面積がおかしい

**A.** KMLファイルの座標系がWGS84（緯度経度）であることを確認してください。本アプリはWGS84楕円体による面積計算を行います。Google Earthで作成したKMLは通常WGS84です。

### Q. 輪作計画が生成されない

**A.** 以下を確認してください：
- ほ場が2つ以上登録されているか
- 作物設定で作物が選択されているか
- 制約条件が矛盾していないか（例: 全作物の面積下限合計がほ場の総面積を超えていないか）

### Q. 農薬発注で計画を選択できない

**A.** 輪作計画を先に作成・保存してください。「🌾 輪作計画」タブで計画を生成し、「保存」ボタンで作付履歴に保存すると、農薬発注の計画選択に表示されます。

### Q. 畑地化開始年度を覚えていない

**A.** 空欄のまま登録できます。集計画面では「開始年度不明」として別枠で表示されます。後から分かった場合は、水田ポリゴン管理画面で更新できます。

### Q. データを間違って登録してしまった

**A.** 各画面に削除機能があります。ほ場登録→ほ場削除、水田ポリゴン→削除ボタンなど。ほ場一覧画面では情報の編集も可能です。

### Q. 複数のユーザーで同時に使えるか

**A.** はい。各ユーザーは自分のアカウントでログインし、それぞれのデータを管理できます。同じ組織に所属するユーザーは共通のデータにアクセスできます。

## トラブルシューティング

### 画面が表示されない / 真っ白になる

1. ブラウザのキャッシュをクリアする（Ctrl+Shift+Delete）
2. ブラウザを最新版に更新する
3. 別のブラウザで試す
4. サーバーが起動しているか管理者に確認する

### 地図が表示されない

1. インターネット接続を確認する（地図はOpenStreetMapから取得）
2. ブラウザの広告ブロッカーを無効にする
3. ページを再読み込みする（F5）

### ファイルのアップロードに失敗する

1. ファイル形式を確認する（KML/KMZ/CSV/GeoJSONなど、指定された形式か）
2. ファイルサイズが大きすぎないか確認する
3. ファイルの文字コードがUTF-8であることを確認する（CSVの場合）

### 「エラーが発生しました」と表示される

1. 操作を再度試す
2. 入力内容に不備がないか確認する（必須項目の未入力、不正な値など）
3. ページを再読み込みして再度試す
4. 解決しない場合は管理者に連絡する

### PDFが文字化けする

1. 日本語フォントがサーバーにインストールされているか管理者に確認する
2. ブラウザでPDFを開く代わりに、ダウンロードして専用ビューアで開く

## 操作の流れ（推奨手順）

初めて使う場合の基本的な流れです。

```
1. 🌱 作物設定 → 作付する作物を選択
       ↓
2. 🗺️ ほ場登録 → 地図上でほ場を登録
       ↓
3. 🗺️ ほ場一覧 → 年度別の作物を確認・調整
       ↓
4. 🏞️ 水田ポリゴン → 水田がある場合は登録（任意）
       ↓
5. 📊 面積集計 → 地目別の面積を確認（任意）
       ↓
6. 🌾 輪作計画 → 制約を設定し最適化を実行
       ↓
7. 💊 農薬発注 → 年間の農薬必要量を算出
       ↓
8. 🧪 防除記録 → 散布実績を記録（栽培期間中に随時）
```
