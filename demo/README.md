# 🌾 輪作計画メーカー Demo

北海道畑作の輪作計画を自動生成するデモアプリです。

## デモ用ログイン

| ロール | ユーザー名 | パスワード | 権限 |
|--------|------------|------------|------|
| 農家 | `user1` | `demo123` | 自分のほ場の閲覧・編集 |
| JA職員 | `admin` | `admin123` | 全ほ場の管理・ユーザー管理 |

## 機能

- 🌾 **輪作計画**: OR-Toolsで最適な作付順序を計算
- 💊 **農薬発注**: 輪作計画から農薬必要量を算出
- 🗺️ **ほ場登録**: 地図でほ場をポリゴン描画、面積計算

## 対応作物

| 作物 | 特徴 |
|------|------|
| てんさい | 糖分原料、連作禁止（4年間隔） |
| 大豆 | 窒素固定、てんさい後に好適 |
| 小豆 | 連作注意、大豆と交互 |
| 春小麦 | 春播き、大豆後に好適 |
| 秋小麦 | 秋播き、てんさい後禁止 |
| 馬鈴薯 | 連作禁止、収穫期が長い |

## 制約

### 禁止遷移（固定）
- **てんさい → 秋小麦**: 作期重複（てんさい5-11月、秋小麦9月播種）
- **春小麦 → 秋小麦**: 病害対策
- **連作禁止**: 同一作物の連続年作付はNG

### 推奨遷移
- てんさい → 大豆（窒素固定で地力回復）
- 大豆 → 春小麦（残留窒素を活用）

## 使い方

### 1. サンプルデータで試す
1. 「サンプルCSV」をダウンロード
2. ファイルをアップロード
3. 「計画を生成」をクリック

### 2. 自分のデータで試す
1. CSVテンプレートをダウンロード
2. 自分のほ場データを入力
3. アップロードして最適化

## CSV形式

```csv
ほ場ID,地区,ほ場名,area,beet_forbidden,R1,R2,R3,R4,R5
F001,北地区,北1号,50,0,大豆,春小麦,てんさい,大豆,春小麦
F002,北地区,北2号,45,0,春小麦,てんさい,大豆,春小麦,てんさい
```

### 列の説明
- `ほ場ID`: ほ場の識別子
- `地区`: 地区名（同地区をまとめて同作物に）
- `ほ場名`: ほ場の名前
- `area`: 面積（a/ha選択可能）
- `beet_forbidden`: 馬鈴薯・てんさい禁止フラグ（1=禁止）
- `R1〜R5`: 過去の作付（和暦）

## 技術スタック

- **最適化エンジン**: Google OR-Tools
- **UI**: Gradio
- **地図**: Leaflet.js + OpenStreetMap
- **面積計算**: WGS84楕円体（pyproj）
